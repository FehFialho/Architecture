## Por que retornar entidades diretamente em uma API pode causar problemas?

Porque dessa forma não esta sendo realizada uma tratativa, seja ela de dados nulos ou errados. Os dados não serão processados antes de serem entregues, podendo gerar imprevistos ou confusões. O mais correto seria criar um UseCase/Handler para fazer o tratamento do dado antes de passar o mesmo para uma camada superior.
